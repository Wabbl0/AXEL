# Scene Patch Interface

## Purpose

Define a stable contract for converting approved layout drafts into scene-edit instructions without directly editing `.tscn` files during draft generation.

## Inputs

- Draft files: `AXEL/axel_project/tools/scene_builder/output/layout_drafts/*_draft.json`
- Approval gate file: `AXEL/axel_project/tools/scene_builder/output/approved_drafts.json`

## Approval File Format

```json
{
  "approved_scene_ids": ["scene_2", "loc_classroom"]
}
```

Only listed scene IDs are converted into patch instructions.

## Output Contract

Generated by `tools/scene_builder/scene_patch_interface.py`:

- `AXEL/axel_project/tools/scene_builder/output/scene_patch_instructions.json`

Each instruction set contains:

- `scene_id`
- `target_scene_path_hint`
- `player_profile` (scale/speed adjustments from selected profile)
- operation list (`ensure_group_node`, `set_player_profile`, `add_or_replace_props`)

## Usage

```bash
python tools/scene_builder/scene_patch_interface.py
```

## Integration Notes

- This contract is intentionally engine-agnostic for the first pass.
- A later executor can map instructions to real Godot edits.
- Unknown/unassigned assets are excluded before this stage by the classifier.
