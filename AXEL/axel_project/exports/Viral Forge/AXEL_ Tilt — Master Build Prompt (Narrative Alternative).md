# AXEL: Tilt — Master Build Prompt (Narrative Alternative)

For: Use INSTEAD of AXEL: Resonance if the narrative/anti-casino angle tests stronger than cosmic. Goal: Steam-shippable cascading-cluster slot roguelite framed as a heist against rigged casinos. Philosophy: Win on narrative, not aesthetic, while same mechanics carry the loop.

## 1. Project Overview

AXEL: Tilt — same cascading-cluster mechanic as Resonance, framed as a heist crew rigging the slots that rig players. Each biome is a casino tier (Strip Mall → Backroom → Penthouse → Sky Vault). The "heat" mechanic adds bust risk: every cascade adds heat, max heat = bust.

**Why this wins:**

- Strongest distinct narrative angle in the sub-genre
- Anti-casino framing = TikTok-policy-safe + discourse magnet (rides the Atlantic gambling-app article wave)
- Doesn't compete on aesthetic with CloverPit/Slots & Daggers — competes on story

Legal: Same as Resonance. Mechanics safe. Theme original.
